# ComfyUI Mobile Remote

这是一个直接运行在 ComfyUI 内部的手机控制页面。

## 特点

- 不注册任何 ComfyUI 节点，不改变原工作流和连线。
- ComfyUI 启动时自动加载插件。
- 手机可通过 Cloudflare 临时公网链接或 Tailscale 地址访问，不需要账号、密码或配对。
- 电脑端 ComfyUI 左侧快捷栏提供独立的手机图标，同时管理两种连接。
- 手机端只显示参数表单、队列、进度和历史，不显示节点画布。
- 所有生成仍由电脑上的原节点和模型执行。
- 支持图片上传、任务停止、失败提示和重新生成。

## 当前安装位置

```text
ComfyUI/custom_nodes/ComfyUI-Mobile-Remote
```

## 电脑端连接面板

1. 启动 ComfyUI，在电脑浏览器打开 `http://127.0.0.1:8188`。
2. 点击左侧快捷栏的手机图标「手机远程」。
3. 面板同时显示「临时公网链接」和「Tailscale」。点击复制，把链接在手机浏览器打开。

临时公网连接使用 Cloudflare Quick Tunnel：默认随 ComfyUI 自动建立，第一次使用会从 Cloudflare 官方 GitHub 下载 `cloudflared` 并核对 SHA256。组件保存在插件的 `bin` 目录，不安装系统服务。开关、重连和「随 ComfyUI 自动连接」均在面板内；关闭公网连接不影响 Tailscale。关闭当前连接只影响本次运行，下次是否自动连接由复选框决定。

公网地址只有在组件实际连接成功后显示，形如 `https://随机名称.trycloudflare.com/mobile`。它在重启 ComfyUI 或重新建立隧道后会变化；不需要 Cloudflare 账号、域名或手机安装网络软件。免费 Quick Tunnel 没有带宽或可用性承诺，实际速度取决于电脑上传速度和到 Cloudflare 的网络。此模式使用 HTTP 和 WebSocket，未使用 Quick Tunnel 不支持的 SSE。

Tailscale 安装并登录、处于在线状态后才显示实际检测到的链接；未配置时显示「配置 Tailscale 后显示链接」。电脑和手机需加入同一个 Tailscale 网络。插件只读取其状态，不更改 Tailscale 配置。

连接设置保存在插件的 `remote_settings.json`；诊断日志保存在 `.runtime/cloudflared.log`。插件目录整体迁移后会根据新电脑的实际地址和端口重新检测，两种链接都不写死在代码中。现有工作流、节点和手机界面保持原有使用方式。

Cloudflared 项目及许可证：<https://github.com/cloudflare/cloudflared>。Quick Tunnel 说明：<https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/do-more-with-tunnels/trycloudflare/>。

## 手机设置同步

手机端顶部刷新按钮左侧显示 `HH：MM已同步`，表示电脑上最后成功保存的时间。有修改尚未保存时显示「待同步」，网络失败显示「未同步」。

- 同步范围：工作流选择、各工作流的模型/尺寸/种子等参数、标签模式/选择/锁定/忽略/自定义词、随机生成开关、重复次数，以及历史收藏筛选和列数。
- 电脑统一保存到 `mobile_settings.json`，保留上一版 `mobile_settings.json.bak`；读取使用内存缓存。它与公网开关的 `remote_settings.json` 是两份不同的配置。
- 新打开的 Tailscale 或临时公网页面优先读取电脑设置，旧网址的浏览器缓存不再覆盖电脑设置。
- 没有变化时一直不上传。每轮从首次变化开始等待 60 秒，再上传这一分钟的最新修改；即使此前长时间空闲，也不会立刻上传。连续变化合并，不反复重置这轮计时；每两次上传尝试至少间隔一分钟，电脑端也限制每分钟最多一次实际保存。
- 随机连发期间暂停上传设置，整批结束后满足时间限制才保存。每个生成任务仍立即提交自己的参数，队列和出图不等同步计时。
- 刷新和关闭页面不会强制上传。未同步改动暂存在原网址的浏览器恢复日志中，手机后台挂起会推迟同步；切换到另一网址前请等待「已同步」。
- 页面回到前台且没有本地修改时读取电脑的新设置；有版本冲突时保留本页修改，设置页可选择「使用电脑设置」或「保留本页修改，稍后同步」，不会静默覆盖。
- 首次升级时，电脑读取旧 `drafts` 草稿，手机已有的本地标签等设置在首次迁移中合并，仍等待一分钟保存；建议先在平时使用的 Tailscale 页面刷新并等待同步，再打开新的公网页面。

## 手机访问地址

ComfyUI 启动后，从电脑端「手机远程」面板复制这台电脑实际检测到的 Tailscale 或临时公网链接，在手机浏览器打开。Tailscale 地址形如：

```text
http://<Tailscale IPv4>:8188/mobile
```

通过局域网或 Tailscale 访问时，ComfyUI 需要监听外部接口，例如启动参数增加 `--listen 0.0.0.0`；仅通过临时公网访问时不要求。

## 第一次使用

1. 启动 ComfyUI。
2. 在电脑浏览器打开普通 ComfyUI 页面。
3. 打开一个准备从手机使用的工作流。
4. 等待约 2 秒。插件会在后台将当前工作流转换成 API 格式并保存。
5. 手机打开 `/mobile`，该工作流会出现在“选择工作流”中。

这一步只是在插件目录保存一份可提交的工作流副本，不修改电脑端工作流。已经同步过的工作流会一直保留，以后只启动 ComfyUI 就能从手机使用，不要求电脑浏览器保持打开。

## 更新工作流

在电脑端修改节点或连线后，保存或重新打开工作流，等待约 2 秒。插件会自动覆盖这个工作流的手机执行副本。

手机页面的“设置”中点击“重新读取工作流”即可立即刷新列表。

## 手机操作逻辑

### 生成

1. 选择工作流。
2. 修改常用参数。
3. 必要时展开“高级参数”。
4. 图生图工作流可以直接从手机上传图片。
5. 点击“加入队列”。

手机修改的是 API 工作流中的输入值，电脑端原有的节点类型、模型加载、节点连线和输出节点保持不变。

### 队列

- 显示正在运行和等待中的任务。
- 可单独停止一个任务。
- 手机断网或切到后台不会中断电脑上的生成。

### 历史

- 显示 ComfyUI 的历史任务和输出缩略图。
- 点击记录可查看结果。
- 手机提交的已完成任务可以使用“重新生成”。

### 设置

- 查看当前页面地址、Tailscale 地址、GPU 和插件版本。
- 重新读取已同步工作流。
- 跳转到完整电脑端 ComfyUI 页面。

## 参数显示规则

以下参数优先显示在常用区域：

- 正向/反向提示词
- 输入图片
- 模型、LoRA
- 宽度、高度、批量数量
- Steps、CFG、Denoise
- 采样器、调度器
- Seed

其他没有连线的标量输入会放在“高级参数”中。已经连接到其他节点的输入不会被手机页面覆盖。

## 访问边界

此版本没有登录和配对。Tailscale 地址的访问权限由 Tailnet 控制。临时公网地址持有者可查看图片、提交生成、上传和删除输出，因此请仅自己使用该链接；随机域名不是额外的身份验证。

公网隧道连接的是仅监听本机回环地址的专用网关，按路径和 HTTP 方法放行手机页面、图片、进度和已有工作流操作。完整 ComfyUI 页面、任意工作流同步接口以及公网连接管理接口不会由此网关转发。原有局域网与 Tailscale 的 ComfyUI 入口不受影响。

## 故障排查

### 手机打不开页面

1. 确认电脑和手机上的 Tailscale 都处于在线状态。
2. 电脑浏览器先测试 `http://127.0.0.1:8188/mobile`。
3. 手机打开从「手机远程」面板复制的 Tailscale 链接。
4. 确认 ComfyUI 启动参数包含 `--listen 0.0.0.0`。

### 手机没有工作流

在电脑端刷新 ComfyUI 页面，打开目标工作流并等待 2 秒，然后在手机设置页点击“重新读取工作流”。

### 工作流提示无效

先在电脑端确认该工作流可以正常运行。自定义节点必须已经安装在这台电脑上。重新打开并同步工作流后再提交。

## 卸载

停止 ComfyUI，删除整个 `ComfyUI-Mobile-Remote` 目录后重新启动即可。插件没有修改 ComfyUI 核心文件。
